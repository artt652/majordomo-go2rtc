# Камеры (go2rtc) для MajorDoMo

Камеры через [go2rtc](https://github.com/AlexxIT/go2rtc): просмотр в панели управления, права, показ на терминалах, временный доступ и гостевые ссылки, WebTorrent. Своих камер у MajorDoMo нет — потоки заводятся в go2rtc, модуль берёт из него только имена; адреса и пароли камер остаются в go2rtc.

Модуль вынесен из «Сообщений» ([artt652/majordomo-messages](https://github.com/artt652/majordomo-messages)): «Сообщения» показывают камеры через него (чат «Камеры», снимок в чат, «Показать на…», временный доступ участникам чата).

## Панель управления → «Камеры (go2rtc)»

- **Камеры** — плитки со снимками (обновляются, пока вкладка открыта); нажатие — живое видео на весь экран (WebRTC через сервер, иначе снимки).
- **Настройки** — адрес API go2rtc (и логин, если go2rtc на другой машине или включён `local_auth`), адрес для устройств, RTSP-сервер go2rtc со своим паролем, ожидание первого кадра, WebTorrent.
- **Права** — кому видна камера: всем, отмеченным терминалам, пользователям. Без отметок — только администратору. Сценарии не ограничены.
- **Ссылки** — действующий временный доступ, гостевые ссылки и ссылки WebTorrent; «Закрыть» — перестаёт работать сразу.

## Входы `api.php/module/go2rtc/…`

| Адрес | Что |
|---|---|
| `frame?src=…&exp=…&sig=…` (`&w=` — ширина) | кадр камеры по подписанной ссылке |
| `whep?src=…&exp=…&sig=…` | согласование WebRTC (POST, SDP) по подписанной ссылке; видео идёт с go2rtc напрямую |
| `guest/<id>` | гостевая страница просмотра одной камеры без входа, до срока ссылки |
| `frame/<id>`, `whep/<id>`, `check/<id>` | кадр, WebRTC и проверка ссылки для гостевой страницы |

`api.php` ядра доступ не проверяет, поэтому модуль пускает только по подписи (секрет модуля) или по действующей гостевой ссылке. Права проверяет тот, кто выдаёт ссылку: панель, «Сообщения», Lovelace. Пароль API go2rtc на устройства и в браузер не уходит.

## Для других модулей и сценариев

```php
include_once(DIR_MODULES . 'go2rtc/go2rtc_lib.inc.php');
if (defined('GO2RTC_API') && go2rtcEnabled()) {
    $file = go2rtcSnapshot('door');                       // снимок в cms/cached/go2rtc (или свой каталог вторым аргументом)
    go2rtcShow(getTerminalsByName('Кухня', 1)[0], 'door', 30);  // показать на терминале 30 с
}
```

| Функция | Что |
|---|---|
| `go2rtcEnabled()`, `go2rtcStreams()`, `go2rtcHas($name)` | настроен ли модуль, имена камер, есть ли камера |
| `go2rtcAllowed($name, $terminal, $user_id, $is_admin)`, `go2rtcCamerasFor(...)` | права на камеры |
| `go2rtcSignedUrl('frame' / 'whep', $name, $exp, $absolute)` | подписанная ссылка на кадр или WebRTC до `$exp` |
| `go2rtcFrame($name, $width)`, `go2rtcSnapshot($name, $dir)` | кадр (JPEG), снимок файлом |
| `go2rtcUrl($name, $format)` | ссылка для устройства: `rtsp`, `mp4`, `hls`, `mjpeg`, `frame`, `webrtc` |
| `go2rtcShow($terminal_rec, $name, $duration, $title, $level)` | показ на терминале: PiPup — окно (RTSP или WebRTC), плеер с экраном — через очередь «Терминалов» (полоса `camera`) |
| `go2rtcLinkCreate($cam, 'chat' / 'guest', $minutes, $members, $by, $by_title)`, `go2rtcLinkGet()`, `go2rtcLinkClose()`, `go2rtcLinks()`, `go2rtcLinkCameras($keys)`, `go2rtcGuestUrl($id)` | временный доступ участникам чата и гостевые ссылки |
| `go2rtcShare($name)`, `go2rtcUnshare($name)`, `go2rtcShares()` | WebTorrent |

Просмотрщик для страниц — `templates/go2rtc/js/viewer.js` (`go2rtcViewer(элемент, {frame, whep, live, …})`): снимки без мигания, «нет связи» после 20 с неудач, живое видео WebRTC, если получилось.

## Файлы

| Файл | Что это |
|---|---|
| `modules/go2rtc/go2rtc.class.php` | Модуль: панель, входы `api()`, событие `MINUTELY`, таблица, перенос настроек |
| `modules/go2rtc/go2rtc_lib.inc.php` | Функции модуля |
| `templates/go2rtc/` | Панель (`action_admin.html`), просмотрщик (`js/viewer.js`) |
| `languages/go2rtc_*.php` | Переводы (английский, русский, украинский) |

Журнал — `cms/debmes/<дата>/go2rtc.log`.

## Установка

Скопировать файлы поверх MajorDoMo и установить модуль. Создаётся таблица `go2rtc_links` и подписка на `MINUTELY`. Если камеры раньше были настроены в «Сообщениях» (или в полной версии «Терминалов»), при установке один раз переносятся настройки, права и действующий временный доступ. Прежние гостевые ссылки (адрес страницы «Сообщения») не переносятся — их нужно выдать заново.

Сам go2rtc ставится отдельно (управление бинарником из модуля — позже). Совместимо с PHP 7 и 8.
